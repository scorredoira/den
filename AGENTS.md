# Completing changes

After any changes in this repository, run `./install` and verify that the
updated app is installed in `/Applications/Den.app` before reporting the task
as complete. Installation is part of the requested work and is already
authorized; do not wait for a separate request to install. Building and
passing tests alone are not enough. If installation fails, report the failure
explicitly.

See [docs/install.md](docs/install.md) for the installation workflow.
