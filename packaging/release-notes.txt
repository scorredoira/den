## What's new in 0.1.11

- **About** shows the version, whether it's up to date, each server's agent and links to GitHub, the release notes and the license.
- **Check for Updates…** (in the Sik menu, or Help on Windows and Linux) checks right away instead of waiting for the next periodic check.
- **Help → Welcome** shows the welcome screen without closing anything.

Also in 0.1.10: any folder can be a workspace and stays across restarts, Settings → Workspaces, and a title bar button for the terminals. In 0.1.9: a fix for the crash when running Settings from the command palette. In 0.1.8: icons in the workspaces column and faster connections to servers after an update.

After upgrading, restart the outdated agent from the workspaces column so that changes made in a terminal refresh the Changes panel. Restarting the agent also restarts its terminals.

## Downloads

Download the archive for your operating system and architecture below.

- **macOS:** unzip and move `Sik.app` to Applications. These builds are not notarized. After attempting the first launch, allow Sik in **System Settings → Privacy & Security → Open Anyway**.
- **Linux:** extract the tarball and run `./install.sh`, or launch `./sik` directly. Requires Ubuntu 24.04 or compatible, a Wayland/X11 desktop and a working Vulkan driver.
- **Windows:** extract the entire ZIP and open `sik.exe`. `install.ps1` optionally installs a Start menu shortcut. These binaries are unsigned.

Install Git, and OpenSSH for remote connections. Every package includes the agent for Linux x86_64 SSH servers. `SHA256SUMS` contains the checksums of the release archives.

[Installation details and requirements](https://github.com/scorredoira/sik#install)
