## What's new in 0.1.5

- **Workspaces column** (formerly Tasks): each row shows its folder name, with the branch only when it differs. A repo's worktrees fold under its checkout. Drag a checkout to move it along with its worktrees.
- **`sik <path>`** opens a folder, or a file in its repo, from any terminal, starting Sik if it isn't running. Over SSH it opens in the app connected to that server. `sik task` is now `sik worktree`.
- **Repo hooks** move from `.task/` to `.sik/` (`create`, `remove`, `format`). Rename the folder in your repos.
- **Automatic updates:** an installed Sik checks for new releases every few hours, installs them and restarts once nothing is unsaved. Terminals keep running across the restart.
- Fix LSP crashes and make language servers sturdier.

After upgrading, restart the outdated agent from the workspaces column so that `sik <path>` and the `.sik/` hooks work. Restarting the agent also restarts its terminals.

## Downloads

Download the archive for your operating system and architecture below.

- **macOS:** unzip and move `Sik.app` to Applications. These builds are not notarized. After attempting the first launch, allow Sik in **System Settings → Privacy & Security → Open Anyway**.
- **Linux:** extract the tarball and run `./install.sh`, or launch `./sik` directly. Requires Ubuntu 24.04 or compatible, a Wayland/X11 desktop and a working Vulkan driver.
- **Windows:** extract the entire ZIP and open `sik.exe`. `install.ps1` optionally installs a Start menu shortcut. These binaries are unsigned.

Install Git, and OpenSSH for remote connections. Every package includes the agent for Linux x86_64 SSH servers. `SHA256SUMS` contains the checksums of the release archives.

[Installation details and requirements](https://github.com/scorredoira/sik#install)
