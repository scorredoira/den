## What's new in 0.1.10

- **Workspaces are folders:** open any folder and it stays in the workspaces column across restarts. If it's a git repo, its worktrees show under it and New Worktree is available. "Add Repo…" is gone, since Open Folder does it, and "Remove from Workspaces" takes a folder off the list without touching the disk.
- **Settings → Workspaces** replaces Repos and Hidden Workspaces: each server's folders and their worktrees, with hide and show on each.
- A title bar button shows or hides the terminals.

Also in 0.1.9: a fix for the crash when running Settings from the command palette. In 0.1.8: icons in the workspaces column and faster connections to servers after an update. In 0.1.7: the focused terminal of a split is marked by its title, and branches show only when they aren't `master` or `main`. In 0.1.6: the menu bar on Windows and Linux, the welcome screen on first launch, the branch in the status bar, and a read-only Changes panel that refreshes on its own.

After upgrading, restart the outdated agent from the workspaces column so that changes made in a terminal refresh the Changes panel. Restarting the agent also restarts its terminals.

## Downloads

Download the archive for your operating system and architecture below.

- **macOS:** unzip and move `Sik.app` to Applications. These builds are not notarized. After attempting the first launch, allow Sik in **System Settings → Privacy & Security → Open Anyway**.
- **Linux:** extract the tarball and run `./install.sh`, or launch `./sik` directly. Requires Ubuntu 24.04 or compatible, a Wayland/X11 desktop and a working Vulkan driver.
- **Windows:** extract the entire ZIP and open `sik.exe`. `install.ps1` optionally installs a Start menu shortcut. These binaries are unsigned.

Install Git, and OpenSSH for remote connections. Every package includes the agent for Linux x86_64 SSH servers. `SHA256SUMS` contains the checksums of the release archives.

[Installation details and requirements](https://github.com/scorredoira/sik#install)
