## Den 1.0

A native IDE for working with coding agents. Every folder you open is a workspace with its files, its changes and its terminals; a git repo's worktrees are workspaces too, so several branches can be open side by side, each with its own Claude Code session.

- **Workspaces on every machine:** this one, SSH servers and, on Windows, WSL distros. Terminals live in an agent next to the files: closing Den doesn't stop them, and they come back as they were.
- **The state of each session at a glance:** red when Claude is asking something, yellow while it works, green when it finished unseen.
- **Code:** tree-sitter highlighting, multiple cursors, Go to Definition, references and completions through language servers, search and replace across the workspace, and Markdown preview.
- **Git:** uncommitted changes, the history and side-by-side diffs. Committing and everything else is done in a terminal.
- **`den <path>`** from any terminal opens a folder or a file in Den.
- **Updates:** Den checks for new releases and installs them; it restarts when you say so. Settings → Updates turns the check off.
- **Help → Keyboard Shortcuts:** every shortcut, grouped by category, with the keys as they are now.

## Downloads

Download the archive for your operating system and architecture below.

- **macOS:** unzip and move `Den.app` to Applications. These builds are not notarized. After attempting the first launch, allow Den in **System Settings → Privacy & Security → Open Anyway**.
- **Linux:** extract the tarball and run `./install.sh`, or launch `./den` directly. Requires Ubuntu 24.04 or compatible, a Wayland/X11 desktop and a working Vulkan driver.
- **Windows:** extract the entire ZIP and open `den.exe`. `install.ps1` optionally installs a Start menu shortcut. These binaries are unsigned.

Install Git, and OpenSSH for remote connections. Every package includes the agent for Linux x86_64 SSH servers. `SHA256SUMS` contains the checksums of the release archives.

[Installation details and requirements](https://github.com/scorredoira/den#install)
